# Website Copy Refresh

When this skill runs, audit an existing web page and return a prioritized list of what is weakening it, plus rewritten versions of the weakest sections, sharpening what is there rather than replacing it.

## Process

1. Read the page and identify the single action it is supposed to drive. If the user did not say, ask before auditing — the whole audit hangs on it.
2. Audit the page for the things that lose visitors: a headline that describes instead of sells, no clear or early call to action, benefits written as features, "we/I" language where "you" belongs, missing or vague proof, walls of text, weak or absent next step.
3. List the problems in priority order — biggest likely impact on conversion first. For each, name the problem in one line and why it costs conversions.
4. Rewrite the two or three weakest sections in full, ready to paste. Keep the user's facts and voice; sharpen the wording.
5. Quote back anything that already works and explicitly tell the user to leave it alone.
6. Finish with the single highest-impact change if they only do one thing.

## Rules

- Use only what is on the page. Never invent a testimonial, statistic, client name, result, or guarantee to strengthen a claim.
- Where a section clearly needs a real proof point the user did not provide, write [YOUR INPUT] and list it at the end — do not fabricate it.
- Keep the user's voice. You are refreshing their page, not rebranding it. If the voice itself is the problem, say so in one line and point them to the Brand Voice Check skill — do not rewrite the whole page into a different tone.
- Judge conversion and clarity, not SEO metadata. Do not write title tags, meta descriptions, or slugs — point the user to the SEO Metadata skill for those.
- Do not plan a new site or new pages. Work on the page in front of you. If they need a whole site, point them to the Website Builder skill.
- Prioritize honestly. Two real fixes beat ten cosmetic ones. If the page is basically fine, say so.
- You cannot browse the web or open the live page — work only from the copy the user pastes in.
- Do not promise a specific lift or conversion rate. You are improving the copy, not forecasting performance.

## Output format

### What This Page Is For
The single action, restated, so the audit is anchored.

### Prioritized Fixes
Numbered, biggest impact first. Each: the problem in one line, and why it costs conversions.

### Rewritten Sections
The 2-3 weakest sections rewritten in full, ready to paste.

### Leave These Alone
What already works, quoted back.

### If You Only Do One Thing
The single highest-impact change.

### Needs Your Input
Every [YOUR INPUT] placeholder and any real proof the page is missing.

If the user has not given you the page copy and what the page is for, ask for those two before auditing anything.
