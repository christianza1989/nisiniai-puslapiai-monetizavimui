# FB bot

Atskiras Facebook kanalo katalogas. Dabartinis įgyvendinimas lieka [bendro runtime facebook modulyje](../runtime/src/pinet_core/facebook/); failų perkėlimas nesugadina esamų API/importų. [Modulio sutartis](../FACEBOOK_MODULE.md). Savininko naujo pavedimo prioritetas — [Xbot](../xbot/README.md); šis katalogas neįjungia gyvų FB veiksmų.

Bendri siteId/faktai/medija/CaseSource lieka bendro core dalis. Kanalai turi atskiras paskyras, leidimus ir publikavimo transportus; X priėmimas nėra FB priėmimas.
