# Tool selection

The installed [Impeccable skill](../../impeccable/SKILL.md) is pinned and adapted for the owner's delegated design workflow. Its bundled reference documents cover art direction, hierarchy, type, responsive work and finishing. Read only the relevant playbook. Use our niche workflow for business truth, domain scope and SEO.

The Windows launcher is `SKILLS/impeccable/scripts/impeccable.cmd`; invoke it with an absolute path when the current directory is the public renderer repository. For a focused read-only source scan, pass the actual active-site markup and stylesheet, using `detect --json --no-config`. Save stdout and stderr separately and record the engine/version and exit code. A source scan does not measure the rendered layout. The CLI's documented URL scan can inspect the rendered page; verify support and use a narrow viewport when needed. Findings require judgement, including false positives.

Use the existing browser skill/CLI for reference inspection and implemented-site screenshots. A new browser MCP is unnecessary when current tools provide the required access. Do not mistake an accessibility-tree snapshot for a visual assessment.

Use existing shared components or native HTML for basic forms/navigation. shadcn/ui's registry MCP is useful when searching and importing real components; it does not choose the site's creative direction. Check each third-party registry's license and dependencies. Magic UI and React Bits are optional sources for a specific justified effect, not a compulsory runtime. React Bits has MIT plus an additional Commons Clause restriction; retain and review its actual license.

If editable canvas work materially helps, evaluate OpenPencil or Penpot's official MCP in the current environment. OpenPencil's MIT editor supports local MCP and Windows; its built-in AI still needs a model/provider. Penpot's free cloud tier and open-source software offer a different option, with a browser plugin and local MCP connection. Neither integration was exercised during the 2026-09-30 research, so do not call them validated or preconfigured. Direct local HTML studies remain an available path without a new account.

Commercial canvas/generator tools are optional. Paper, Figma's official MCP and 21st have documented free-plan limits; pen.dev is currently free rather than guaranteed free forever. Do not make those services prerequisites for the network or claim unlimited free AI generation. Existing Codex/ImageGen usage still consumes the user's plan or provider resources.
