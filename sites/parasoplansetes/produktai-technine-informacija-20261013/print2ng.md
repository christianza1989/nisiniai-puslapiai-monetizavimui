# Print2NG

„Print2NG“ – virtualus spausdintuvas dokumentams siųsti į NextGen šeimos planšetes. Programoje pasirinkę spausdinimą, dokumentą perduodate į NG įrenginį, žmogus pasirašo jo ekrane, o pasirašytas failas grąžinamas atsisiųsti. Taip galima pradėti pasirašymą iš Word, Excel ar kitos spausdinimo funkciją turinčios programos.

## Techniniai reikalavimai

| Parametras | Reikšmė |
|---|---|
| Windows | 10 / 11; tik x86 arba x64 |
| Windows ARM | ARM32 ir ARM64 nepalaikomi |
| macOS | Nuo 13.2 |
| Linux | Nurodytas palaikymas; distribuciją tikslinti |
| Procesorius | Dviejų branduolių: min. 1 GHz, rekomenduojama 2 GHz |
| RAM | 2 GB |
| Laisva disko vieta | 300 MB, įskaitant laikinuosius duomenis |
| Ekranas | Bent 1024 × 768; 16 bitų spalvos |
| Planšetės | nextGen Pad 5 ir duraSign Pad NG 10 |

## Pasirašymo stebėjimas ir išsaugojimas

Kompiuteryje rodomas planšetės pasirašymo vaizdas. Darbuotojas gali stebėti eigą ir valdyti planšetės mygtukus. Failas išsaugomas per „Išsaugoti kaip“ arba iš anksto nustatytame aplanke. Po išsaugojimo programa gali užsidaryti arba susimažinti.
