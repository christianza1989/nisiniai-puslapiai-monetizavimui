# eSignatureOffice

„eSignatureOffice“ – Windows programa PDF/A dokumentams peržiūrėti, užpildyti ir pasirašyti. Ji tinka darbo vietai, kur darbuotojas pateikia dokumentą klientui, o pasirašytą failą reikia išsaugoti arba perduoti kitai sistemai. Parašas įterpiamas tiesiai į dokumentą.

## Techniniai reikalavimai

| Parametras | Reikšmė |
|---|---|
| Operacinė sistema | Windows 10 / 11 |
| Minimalus procesorius | Dviejų branduolių, 1 GHz |
| Rekomenduojamas procesorius | Dviejų branduolių, 2 GHz |
| RAM | Min. 1 GB; rekomenduojama 2 GB |
| Disko vieta | 150 MB, įskaitant laikinuosius duomenis |
| Ekranas | Bent 1024 × 768, 16 bitų spalvos |
| Dokumentai | PDF/A; formų ir parašo laukai |
| Duomenų apsauga | Biometrinių duomenų RSA šifravimas iki 4096 bitų |

## Dokumentų apdorojimas ir integracija

Parašo laukus galima nustatyti pagal teksto žodžius arba jau sukurtus PDF laukus. Programa leidžia atskirti privalomus ir neprivalomus parašus, užpildyti formą, slinkti dokumentą ir keisti mastelį. Makrokomandomis galima automatizuoti failo pavadinimą, išsaugojimą, spausdinimą ir perdavimą.

Integracijai naudojami paleidimo parametrai, XML bei konfigūracijos failai; galima įterpti OCX komponentą. Dokumentai gaunami ir perduodami HTTP(S) ar FTP, rezultatus galima siųsti el. paštu. Konfigūraciją galima eksportuoti į `.scs` failą kitoms darbo vietoms. TCP ir Citrix moduliai skirti terminalinių serverių aplinkoms. Pateikus PDF/A dokumentą, išsaugoma PDF/A išvestis.
