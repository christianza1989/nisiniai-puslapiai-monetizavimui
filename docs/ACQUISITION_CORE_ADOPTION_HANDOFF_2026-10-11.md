## Prijungimo darbai ir priėmimas

1. **Priimti šaltinius savo šakoje.** Fetch abu repo, atlikti [Git freshness](CODEX_GIT_WORKFLOW.md), perskaityti actual AGENTS / skills / sutartis. Per [issue66](https://github.com/christianza1989/nisiniai-puslapiai-monetizavimui/issues/66) užfiksuoti savo source SHA ir tikslų bootstrap / migration / API / config / task / portal failų langą. Gerbti kitų sesijų checkout ir reservations; naujas owner takeover turi būti aiškus. Peržiūrėti ir integruoti PR59 bei reikalingus native / control / I2 paketus; vien fetch nėra adapterio adoption.
2. **Pagrindinės DB migracija ir grants.** Pagal actual I2 grandinę prijungti acquisition migraciją (siūlyta0012 su down_revision0011), metadata ir startup. Taikyti [reprodukuotą bootstrap pataisą](ACQUISITION_I2_BOOTSTRAP_PROPOSED.patch) pagal savo actual source ir [jos QA](ACQUISITION_I2_BOOTSTRAP_QA_2026-10-10.md). Vien `acquisition_*` exclusion neatšaukia anksčiau suteiktų UPDATE/DELETE. Trusted complete-schema transaction turi vykdyti module-owned `runtime_grants_sql()`; receipts palikti SELECT/INSERT, be UPDATE/DELETE, visur forced RLS. Partial schema turi būti atmesta. Pakartoti actual full-chain bootstrap ir backup/restore / rollback bandymą, išsaugant control teises ir pirmus FAIL.
3. **Normal API ir viena projekcija.** Prijungti acquisition handler / config prie tikro core entrypoint. Native callback naudoja užregistruotą adapterį ir raw-body MAC / replay sutartį; direktoriaus read tool gauna scope iš aktualios serverio autentifikacijos, membership ir grants. Browser-selected Scope nėra autoritetas. Portalas ir chat vartoja tą patį [CaptureLedgerSnapshot](../agent-business-core/contracts/acquisition-projection-v1/README.md), current būseną ir watermark. Trūkstamų discovery / siuntimo / inbox / cost šaltinių metrikos lieka null; all-time skaičiai nepavadinami savaitės ataskaita. Dabartinė biblioteka capture-only; production ar period report plėtra reikalauja atskiro aiškaus kontrakto ir actual priėmimo.
4. **Tikros acquisition užduotys ir susirašinėjimas.** Pritaikyti existing generic task runner typed acquisition darbams; nekopijuoti I2 runner ir nesukurti netikro Conversation. Patvariai prijungti discovery→qualification→draft→exact review→outbox/capture→inbound→signup attribution. Užtikrinti scoped dedup, budžetus, pause / expiry / stop, uncertain attempt ir restart/replay. Inbound turi išlaikyti realų Message-ID / thread / gavėjo binding ir vieną idempotentį priėmimą. Native production outbox / destination / backup / dabartinės eligibility šaltiniai turi būti realiai prijungti ir patikrinti.
5. **Pritaikyti reply būsenas prieš kitą darbą.** `marketing_suppression_required` ir `marketing_hold_required` turi būti patvariai išsaugoti ir tikrinami prieš queued / būsimą marketing veiksmą. Atsisakymas ar skundas sustabdo marketing net kai sena suppression reikšmė false. Sąlyginis būsimas kontaktas saugo exact `resume_condition_quote`; quote nesuteikia automatinio resume. `privacy_handoff` siunčia nulį laiškų ir reikalauja tikro operatoriaus / inbound Case priėmimo. Kol nėra actual idempotentio handoff ACK, `handoff_executed=false`; campaign pause / expiry negali prarasti privatumo prašymo. [Canonical skill](../SKILLS/niche-client-acquisition/SKILL.md) ir [copy QA](ACQUISITION_COPY_REVIEW_QA_2026-10-10.md) aprašo atkurtus gedimus ir regresijas.
6. **Priimti visą normal kelią.** Su naujais `example.test` fixture gavėjais paleisti normal site→core→portal→director→worker capture-only bandymą: draft / captured letter / incoming reply / hold / refusal / privacy handoff / native OTP / operator approval / activation / withdrawal. Įrodyti realių procesų ir DB restart, exact replay be naujo send, changed-body conflict, foreign scope denial, original expiry ir stop. Neatgaivinti senų consumed / expired kvietimų. Iš naujos sesijos perskaitytas report ir portalas turi rodyti tuos pačius realiai committed duomenis. Tik tada pažymėti atitinkamą actual adapterio priėmimą.

Originalūs tyrimo recheck terminai `2026-10-11T05:03:44.774098Z` ir `2026-10-11T05:17:54.111146Z` jau praėjo.
