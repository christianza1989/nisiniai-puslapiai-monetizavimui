# Organise source images without breaking public media families

Read [PROJECT_CONTRACT](../PROJECT_CONTRACT.md) before using this skill in the network. Role: **utility**; it contributes the scoped task below and does not silently expand a domain build. Use current site facts, authorization and actual tool capabilities.

## Workflow

1. Inspect actual images and relevant nonprivate metadata; do not invent model, place, person, project or rights from a filename.
2. Group private source assets and record original-to-public-family mappings. Do not rename/move immutable approved WebP IDs or exposed package paths.
3. Use MEDIA_CORE for conversion; this helper is not a separate resize tool. Preserve originals, credits and known rights; duplicates require an actual retention decision.

## Handoff

A source-image manifest, real descriptive naming and stable media/publication relationships.
