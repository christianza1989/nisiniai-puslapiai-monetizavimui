# Existing private plan reconciliation

Use `content-studio/scripts/reconcile-private-plan.mjs` with an explicit private `STUDIO_DATA_DIR`. Prepare a private request with `siteId`, actual `canonicalHost` and `locale`, SHA-256 of `model.stable(await getSite(siteId))` as `expectedSiteHash`, exact source-plan byte SHA, actual instruction fingerprint, final `coverageTarget`, complete `updates` and `retire` decisions. This is the common model/store workflow, not a new planner or publication path.

Each update retains `pageId` and `slug`, carries the full private `brief`, actual same-site `linkSuggestions` and `pillarPageId`. Optional `metadata` permits title/description/intent/cluster changes only on unwritten, unapproved plans. Dates remain unchanged. Written or approved public revision fields, media, sources, approval snapshots and generation receipts are preserved. The private brief includes the complete answer, source needs, original contribution, media brief, keyword ownership and typed planned destinations. Candidates remain unverified evidence.

Each retirement carries the real `pageId`, surviving `targetPageId` and reason. Only unwritten, media-free, unapproved plans can retire. Their exact original snapshots and old-to-surviving UUID relationship move into private `site.retiredPlans`; they leave active `site.pages` and drafting queues. Existing body/public links to a retired page block the transaction. A complete decision for every current page and cycle-free surviving hierarchy are required.

The transaction uses the existing `DATA/.model-write.lock`, rejects active queued/running site jobs and stale snapshots, validates everything before one atomic site replacement and retains a reconciliation receipt in the same store. Exact replay verifies the stored result and adds no history entry; a subsequent conflicting state requires explicit review. Keep the initial site snapshot and request private for controlled recovery; do not edit runtime JSON directly or copy studio history to Git.

Run `--check` for a snapshot/count inspection, then `--apply <private-receipt.json>` for the guarded transaction. A successful check is not acceptance of all transaction gates. Inspect the result with the shared model/API, verify preserved revisions and inspect `draftPageData → buildEditorialPrompt` without calling a paid writer. `draftPage`, draft batches and autopilot use that shared prompt projection. Existing generic V2 generation remains deliberately blocked until its separate rich-output adapter is accepted.

A Node server already running retains its imported modules. Check active jobs, restart only the owned isolated studio process before its next job, and verify its current API. Other tenants/processes must remain intact. Reconciliation is private planning state; it does not approve text, create media, export a release, change production, or certify clinical claims, indexing or rankings.
