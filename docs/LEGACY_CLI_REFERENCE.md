# Rankinių CLI ir istorinių migracijų paskirtis

2026-10-17 šaltinio peržiūra, [issue197](https://github.com/christianza1989/nisiniai-puslapiai-monetizavimui/issues/197). Šis indeksas paaiškina, kodėl ankstesniame [inventoriuje](CORE_DOCUMENTATION_INVENTORY_2026-10-17.md) minėti failai išsaugoti. Jie šiame darbe nevykdyti; dabartinė privati studijos būsena ir migracijų užbaigimas netikrinti. Failo buvimas ar nerastas importas savaime neįrodo jo nenaudojimo.

Žemiau išvardyti istoriniai bootstrap, migravimo ir atkūrimo scenarijai nėra prižiūrimas naujos svetainės ar turinio publikavimo pradžios taškas. Dabartiniam darbui taikomi studijos modelio, medijos, redakcinės peržiūros ir publikavimo sutarčių keliai. Eksportavimo priemonės turi atskirą dokumentuotą paskirtį.

Naują įprastą turinio darbą pradėk nuo [studijos instrukcijų](../content-studio/README.md) ir [CONTENT_CORE](../CONTENT_CORE.md). Migracijos vykdymui reikia konkretaus duomenų pakeitimo pavedimo, dabartinių faktų, revizijų ir atkūrimo patikros pagal galiojančias sutartis. Šis indeksas nesuteikia seno `actorId` naujai redakcinei peržiūrai ir nepatvirtina, kad šie CLI atitinka visas vėliau pakeistas API ar peržiūros taisykles.

Peržiūrėti abu sekami `package.json`, GitHub workflow registrai, studijos `server.mjs`, `generator.mjs`, `model.mjs` ir `editorial-skill.mjs`: šie septyni konkretūs scenarijai nėra automatiškai paleidžiami paketų start/test komandomis ar CI. Redakcinių instrukcijų įkėlimas naudoja aiškų SKILLS failų sąrašą; studijos svetainės atrandamos iš JSON. Tai ribota šaltinio analizė, ne visų išorinių rankinių kvietimų paneigimas. CLI failai šiame pakete nepakeisti.
