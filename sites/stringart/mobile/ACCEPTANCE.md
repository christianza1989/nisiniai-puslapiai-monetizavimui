The important failures were retained privately: initial phone inset overlap, a reload race in the test runner, two cancelled helper-install attempts, and a real document import error. Android's document provider reported a freshly exported JSON file as zero bytes, so WebView File.text() returned an empty string. The wrapper now reads the explicitly selected/granted URI with a bounded 400 KB InputStream, independent of metadata, and passes its text to the same strict importer used in the browser. The real native round-trip then passed. Locked-phone attempts were environment failures, separate from the final unlocked passing run.

AppJourney uses the actual solver for the portrait. Its short four-connection CMYK fixture tests only tie-on, colour readiness and completion, and is deleted by its own ID. It does not prove a full colour portrait's physical appearance. Device assertions may invoke actions inside our own WebView; document selection and keyboard focus use real native input events. The diagnostic journey temporarily keeps its own view awake; the normal app keeps the screen awake only during voice guidance. Normal delivered builds exclude both instrumentation runners.

Generated decorative artwork is separate from algorithm output. The supplied sample fixtures finish Quick at 1,400 and Detailed/Fine at 1,430 connections; the live phone crop run finished at 1,390. Early stopping and crop/resampling account for varying actual counts. Straight-thread estimates exclude wraps and ties. Photorealism, thread tension and actual material compatibility require a physical pilot.

Light phone mode is the tested target. Tablet layouts, a dark scheme, a broad Android/device matrix, TalkBack, store signing/distribution, supplier activation and machine control remain outside this local acceptance. The ten-partner system follows the owner's app-first priority in a separate requested chat; a plan or mock dataset is not an accepted backend.

Private captures, failures, waveform, APKs and receipts stay under ignored mobile/qa and external local delivery folders. No phone identifiers, customer photos or runtime databases are committed.
