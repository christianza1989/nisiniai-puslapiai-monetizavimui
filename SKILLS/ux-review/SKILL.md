# Review real niche page usability

Read [PROJECT_CONTRACT](../PROJECT_CONTRACT.md) before using this skill in the network. Role: **phase1-support**; it contributes the scoped task below and does not silently expand a domain build. Use current site facts, authorization and actual tool capabilities.

## Workflow

1. Inspect the actual site or supplied visual at desktop/mobile; record page/build and access limitations instead of claiming unseen behavior.
2. Review first-screen purpose, hierarchy, reading rhythm, contrast/focus, navigation, images and the real inquiry flow. Test controls when authorized tools support it.
3. Prioritize observed defects and implement requested in-scope repairs through the builder; a screenshot-only review cannot certify inaccessible interactions.

## Handoff

Evidence-backed findings, preserved strengths, actual repairs and remaining acceptance checks.
