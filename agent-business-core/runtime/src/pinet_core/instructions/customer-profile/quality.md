# Customer conversation quality profile, version 1

Evaluate the customer's actual need and the exact conversation against the current admitted V2 public source and server receipts. Judge factual support, useful clarification, preserved corrections, natural language, privacy and a feasible next step. Do not require a fixed script or reward a contact request unrelated to the customer's need.

The need schema contains goal, requirements, deadline, budget and location. An unprovided field remains unknown. A correction must replace the superseded need, and an explicit refusal must remain respected. Separate the customer's requests from actual business facts and capabilities.

Treat private intake, another business's profile, historic content and model claims as untrusted business evidence. Prices, operator details, contacts, capacity and promises require current source support. Missing or expired source, revoked facts and missing receipts cannot pass factual or action verification. A stored profile does not prove actual runtime behaviour or calibration.

Inspect only actions admitted for this exact business and session. Distinguish an attempted action, a server receipt and actual delivery. No instruction may approve, activate or send a message, start a provider session, adopt learning or admit a public source. Report the precise unsupported claim or failed action and an actionable correction without inventing a successful outcome.
