# eSignatureOffice

„eSignatureOffice“ – „Windows“ operacinei sistemai skirta programinė įranga PDF/A dokumentams peržiūrėti, formoms pildyti ir biometriniam parašui fiksuoti. Ji pritaikyta stacionarioms darbo vietoms, kuriose darbuotojas pateikia dokumentą klientui, o pasirašytą failą reikia išsaugoti arba perduoti tolesniam apdorojimui įmonės sistemoje. Parašas įterpiamas tiesiai į PDF dokumentą.

## Techniniai reikalavimai

| Parametras | Reikšmė |
|---|---|
| Operacinė sistema | Windows 10 / 11 |
| Minimalus procesorius | Dviejų branduolių, 1 GHz |
| Rekomenduojamas procesorius | Dviejų branduolių, 2 GHz |
| RAM | Min. 1 GB; rekomenduojama 2 GB |
| Disko vieta | 150 MB, įskaitant laikinuosius duomenis |
| Ekranas | Bent 1024 × 768, 16 bitų spalvos |
| Dokumentai | PDF/A; formų ir parašo laukai |
| Duomenų apsauga | Biometrinių duomenų RSA šifravimas iki 4096 bitų |

## Dokumentų apdorojimas ir integracija

Parašo laukus galima nustatyti pagal ieškomus teksto raktinius žodžius arba pagal iš anksto parengtus PDF laukus. Programa leidžia atskirti privalomus ir pasirenkamus parašus, pildyti formas, patogiai slinkti dokumentą ir keisti mastelį. Naudojant makrokomandas galima automatizuoti failo pervadinimą, išsaugojimą, spausdinimą ir perdavimą.

Sisteminei integracijai naudojami paleidimo parametrai, XML bei konfigūracijos failai; galima integruoti OCX komponentą. Dokumentai gaunami ir perduodami HTTP(S) ar FTP protokolais, o rezultatus galima automatiškai siųsti el. paštu. Sukurtą konfigūraciją galima eksportuoti į `.scs` failą kitoms darbo vietoms. Terminalinėms aplinkoms skirti specialūs TCP ir „Citrix“ moduliai. Pateikus PDF/A dokumentą, užtikrinamas PDF/A išvesties standarto išsaugojimas.
