# Owned Instagram read feed

Official Instagram API with Instagram Login, read-only `instagram_business_basic`. Intended for a professional account the owner manages and adds in the Meta dashboard. No scraping, third-party customer onboarding, messaging or content publishing. Meta owns the token lifecycle and may require a new human consent after revocation, expiry or policy/security changes; scheduled refresh cannot bypass these gates.

An isolated Worker and KV hold the connection and latest48media records. Existing site's service binding exposes only bounded feed/media routes. A scheduled30minute sync reads media; a long-lived Dashboard token is refreshed every7days (never during its first24hours). Initial expiry stays unknown until the provider supplies expires_in. Validate expected username before storing/serving. Only known mediaID proxies stream whitelisted Meta CDN URLs; no arbitrary user-provided upstream URL. Short transient failures preserve a maximum6hour snapshot; revoked/expired credentials close the feed and do not silently reseed.

Setup: own site config, actual KV namespace, private `INSTAGRAM_SEED_TOKEN`, `INSTAGRAM_USERNAME`, pinned API version, `INSTAGRAM_ENABLED=1`; use existing pinned Wrangler. The app dashboard's Generate token flow yields a60day token after real owner consent. Import through private stdin/file only, then let cron establish/refresh the durable connection. `connection`, `feed`, `status` are private KV keys; none is a public status/admin endpoint. Public JSON excludes tokens, raw provider payload/errors/cursors/CDN links. No authentication/login/token endpoints are served by this Worker.

Verify genuine username/media and cron in production independently of fixture tests. Reconnect by replacing only the private token and deleting this connector's disconnected connection key via trusted CLI; never expose reset/import endpoints. On permanent disconnect, disable its cron, revoke the Meta connection/token, remove its seed secret and delete only this connector's KV keys. Remove service binding/component separately without changing unrelated commerce, DNS or customer data.

Contracts: [Meta Business Login](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/business-login), [Get Started](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/get-started). API errors and signed CDN URLs are treated as untrusted input. Tokens are not a guarantee of permanent authorization.
