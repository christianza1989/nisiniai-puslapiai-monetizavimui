# Distinguish overlapping intents from measured query competition

Read [PROJECT_CONTRACT](../PROJECT_CONTRACT.md) before using this skill in the network. Role: **phase1-support**; it contributes the scoped task below and does not silently expand a domain build. Use current site facts, authorization and actual tool capabilities.

## Workflow

1. Compare real page questions and answers first; similar wording alone is not cannibalization.
2. Use scoped query/page/time data where accessible. Separate a content-overlap hypothesis from measured competition and attribution uncertainty.
3. Prefer differentiation or a useful consolidation; do not delete/redirect pages from keywords alone. A migration needs reviewed equivalent targets and shared host-aware tests.

## Handoff

Page-pair findings, evidence/uncertainty and a concrete differentiated or consolidation plan within authorized scope.
