ImageGen iliustracijos nežymėti kaip tikro kliento projekto. Tikrinti mobilų Lighthouse su realiu puslapiu ir vaizdais; aukšto balo nežadėti be matavimo. Tikras gautas laiškas/skambutis nėra tas pats, kas nuorodos paspaudimas.

**Vaizdų priėmimas 2026-09-30:** kiekvienas pradinis gidas turi peržiūrėtą temos vaizdą; homepage ir gidų indeksas turi prasmingų papildomų vizualų bei teisingas miniatiūras. Teisiniai/pasitikėjimo tekstai gali būti be dekoratyvios fotografijos su pagrįsta išimtimi audite. Savininkas nenori matomo ImageGen/modelio ženklelio prie originalių vaizdų: kilmę saugoti medijos žurnale ir redakcinėje metodikoje, išlaikyti būtinas trečiųjų šalių licencines autorystės žymas. Patikrinti realius srcset failus, mobilų vaizdą ir Article image; vien media įrašas ar prompt nėra vaizdo įrodymas.

**Automatinė medija:** visos nišos naudoja [MEDIA_CORE.md](MEDIA_CORE.md). PNG/JPEG/WebP importuoti per studijos GUI, `saveResponsiveAsset` arba bendrą `content-studio/scripts/import-image.mjs`; nekurti naujo optimizatoriaus kiekvienam domenui. Sistema automatiškai kuria WebP dydžius, saugo originalą privačiai ir vienu pasirinkimu priskiria variantų šeimą. Core `imageSrcSet` ir tikrą CSS atitinkantis `sizes` parenka failą; kompozicija/alt/teisės ir actual Lighthouse lieka priėmimo vartai. Media prompt sutartis įtraukta į abu Codex CLI režimus ir jų instrukcijų fingerprint.

Bendro techninio SEO/GEO sutartis aprašyta `SEO_GEO_CORE.md`. Naujam nišiniam domenui naudoti tą patį host-aware rendererį, publikavimo predikatą, canonical, sitemap, robots, JSON-LD ir LLM išvestis; nekeisti jų kopijomis kiekvienoje svetainėje. Schema turi atitikti matomą turinį. `llms.txt` yra papildomas indeksas, ne paieškos reitingo pažadas. Po core keitimo paleisti `npm run test:core` ir `npm run test:seo-smoke` prieš sujungiant tikrą domeną.

Prieš pirmą realų paleidimą būtini veikiantys kontaktai, patvarus užklausų saugojimas ir pristatymas, atskiras domeno matavimas, privatumo tekstai, DNS ir tinkamas komercinis hostingas. Vėlesnių nišų papildomos verslo funkcijos priklauso nuo išmatuotų rezultatų.
