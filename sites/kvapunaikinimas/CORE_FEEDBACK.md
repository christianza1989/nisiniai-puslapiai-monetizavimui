The first plain native-body import retained words but lost incumbent presentation. A text-only261-fragment PASS was insufficient evidence of a visual replica. The owner requested the reproduced audit findings repaired.

1. Preserve emphasis, ordered-list starts and links with bounded metadata referencing native blocks. Bind ranges to block digests and the layout to a page digest so a future native edit cannot apply stale ranges to different prose. A mismatch falls back to native content. 3. A WordPress `-800x450` or similar suffix can describe the displayed crop, not a redundant resize. Import the displayed source through canonical media ingestion, preserve original bytes/cache and select by native asset ID where alt text is ambiguous. Attach referenced families per page rather than the entire site collection; avoid the native120-variant limit.

Separate a process strip and price panels by role.
5. Test complete desktop/mobile routes and native interaction states. Capture actual viewports for fixed backgrounds: full-page screenshots can omit an offscreen fixed background.
