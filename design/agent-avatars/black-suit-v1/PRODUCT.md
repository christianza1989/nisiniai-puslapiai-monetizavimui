# Verslomatika agent-team hero concept

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Business owners who need to understand how to give one request to a coordinator and work with a specialist team. The owner explicitly wants a modern clear Codex-like workspace and a lively public presentation of cooperating agents.

## Product Purpose

Explain one idea → coordinator → specialist work → combined result. This scoped concept previews seven original black-suit animated character PNGs in a homepage hero; it does not replace the homepage owned by the separate session.

## Brand Commitments

Verslomatika; Lithuanian. Owner explicitly requested black suits in a Men in Black inspired style, rounded Codex-like dark surfaces, clear icons/bold hierarchy and premium motion. The seven generated original PNGs are approved only as requested generated output, not a human acceptance of this hero composition.

## Capabilities and Constraints

The live platform and actual backend benchmark are separate from the illustration. Seven portraits do not prove seven activated runtime agents. No fictional customers, sales, guaranteed scores, partnership or production readiness. Example interactions below are explicitly illustrative. The primary prototype link opens the actual local platform; no external submission occurs.

## Stack

Scoped static HTML/CSS/JavaScript concept using exact existing PNGs. Routine implementation choices delegated in the project instructions. No new framework, package, global design authority or production edit.
