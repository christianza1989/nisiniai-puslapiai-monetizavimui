# Private text provenance

`content-studio/src/text-provenance.mjs` stores immutable records under private `STUDIO_DATA_DIR/text-provenance/<siteId>/<pageId>/<revisionHash>.json`. It verifies the revision against the model's actual current or preserved published snapshot. This sidecar never changes page/public package schemas, editorial reviews, approvals or releases. It is not loaded by HTML/schema/sitemap/LLM projection.

`primaryWriter` answers who wrote most of the prose; `originClass` answers whether the prose includes mixed contributions. Gemini prose with Codex review remains Gemini. Gemini prose containing Codex-written sentences is Gemini-primary and mixed, with exact contribution excerpts and hashes. Legacy unknown authorship must remain unknown. Observed UI mode does not establish the backend model ID; that field stays null unless actual model metadata supplies it.

CLI: `node content-studio/scripts/text-provenance.mjs record <siteId> <input.json> <pageId>`. Input includes `revisionHash`, `primaryWriter`, `authoringMode`, `reviewer`, `codexRole`, optional `provider`, `modelUi`, `thinkingUi`, `backendModelId`, `modelEvidence`, `jobId`, `promptVersion`, `conversationUrl`, `authoredAt`, `lineage` revision hashes and `contributions`. A contribution has `writer`, exact final `excerpt`, `role` and `evidence`. Known authoring needs local `artifacts` paths for `prompt`, `inputEvidence`, `rawResponse`, `finalSource`; observed model evidence needs `modelEvidence` artifact and a truthful limitation. The helper copies original artifact bytes into content-addressed private storage and calculates their hashes. It separately preserves the canonical model revision payload and hashes actual final model body/text, so historical revision integrity remains verifiable after subsequent edits. Repeating identical input is idempotent; conflicting evidence for an existing revision is rejected. New page revisions get new records; old records and original sources remain intact.

`list <siteId> [filters.json]` supports `primaryWriter`, `originClass`, `modelUi`, `pageId`, `revisionHash`, `currentOnly`. Examples: `{"primaryWriter":"gemini"}`, `{"primaryWriter":"codex"}`, `{"originClass":"mixed"}`, `{"modelUi":"4 Argon"}`. With `currentOnly:true` stale historical revisions are excluded. `verify <siteId>` checks stored artifacts, model revision hashes and final text/body hashes, including preserved historical revisions. These checks do not prove authorship, truthful UI observation or prose quality; reviewers must inspect their evidence.

Do not commit private registry files/prompts/responses/account information. Never import the registry or copy it into a release/public directory. Final rendered/privacy checks remain part of normal content acceptance. Missing browser access or uncertain legacy origin must not be replaced with guessed model labels.
