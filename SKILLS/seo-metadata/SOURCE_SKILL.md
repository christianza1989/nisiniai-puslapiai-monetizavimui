# SEO Metadata

When this skill runs, turn a finished page and its target keyword into complete, ready-to-paste metadata, using only what is actually on the page.

## Process

1. Read the page copy and identify what it is actually about. If the target keyword is missing, ask for it before writing anything — do not guess it.
2. Write the title tag: 60 characters or fewer, primary keyword near the front, one reason to click. Show the character count.
3. Write the meta description: 155 characters or fewer, written to earn the click, includes the keyword naturally and the main benefit or action. Show the character count.
4. Write the URL slug: short, lowercase, hyphenated, keyword-first, no stop words, no dates.
5. Write two or three H1 options that match the search intent — these are on-page headings, distinct from the title tag.
6. Write image alt text for each image the user lists: describe what the image shows, plainly, no keyword stuffing.
7. If the user asked for it, write an FAQ schema-ready block: 3-5 question/answer pairs drawn only from the page content.
8. Finish with the single highest-impact on-page SEO improvement you can see from the copy itself.

## Rules

- Use only what is on the page and the keyword the user gives you. Never invent a search volume, a difficulty score, a statistic, or a competitor claim.
- Do not promise rankings, positions, traffic numbers, or timelines. You are optimizing metadata, not forecasting results.
- Do not rewrite the page's body copy. If the copy itself needs work, say so in one line and point the user to the Website Copy Refresh skill — your job here is the metadata.
- Respect the character limits exactly and show the count next to the title and meta so the user can verify.
- Keep the keyword natural. One clear use in the title and once in the meta beats stuffing.
- Alt text describes the image for a person who cannot see it. Accuracy first, keywords only if they are genuinely what the image shows.
- You cannot browse the web, check live rankings, or open Search Console. Work only from the copy the user pastes in.
- If the page is missing something the metadata needs, list it under Needs Your Input rather than inventing it.

## Output format

### Title Tag
The title, with its character count.

### Meta Description
The description, with its character count.

### URL Slug
One recommended slug.

### H1 Options
2-3 on-page headline options.

### Image Alt Text
One line per image the user provided.

### FAQ Schema (optional)
3-5 Q&A pairs, only if requested, drawn only from the page.

### One SEO Improvement
The single highest-impact on-page change, based only on the copy.

### Needs Your Input
Anything the metadata needs that the page did not provide.

If the user has not given you the page copy and the target keyword, ask for those two before writing anything.
