# StepOver duraSign Pad NG 10

„duraSign Pad NG 10“ pats apdoroja PDF dokumentą, rodo jį ekrane, užfiksuoja parašą ir parengia pasirašytą failą. Pagrindinį pasirašymo procesą galima valdyti naršyklėje. Didesnis ekranas tinka darbo vietai, kur klientui reikia perskaityti dokumentą prieš pasirašant.

## Kaip naudojama

Per USB planšetę valdo prijungtas kompiuteris. Pridėjus Ethernet Connection Kit, ja paeiliui gali naudotis skirtingi tinklo kompiuteriai. Integracijai siūlomos REST ir .NET sąsajos, taip pat Print2NG. Formoms pildyti pačioje planšetėje skirtas papildomas NG Pad Feature Extension.

## Programos ir prijungimas

PDF nurodo eSignatureOffice ≥7.X ir SimpleSigner ≥8.X, kai pasirenkamas darbas per šias programas. NG integracijai yra įrenginio REST API, NextGen API (.NET) ir Swagger sąsaja. Tinklo priedai su 10/100 Mbit/s adapteriu ir maitinimo šaltiniu perkami atskirai.
