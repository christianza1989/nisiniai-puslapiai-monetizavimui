2026-10-14. Šis dokumentas aprašo patikrintus source apribojimus ir reikalingą ankstyvą migracijos bandymą. Savininkas pasirinko auditą ir planą, todėl shared pataisos ir nauja svetainė šiame etape nerealizuojamos. Tai užduoties apimties riba, o ne tariamas shared upgrade PASS.

Patikrintos source ištraukos ir ribų skaičiavimas yra `artifacts/core-compatibility-evidence.json`; jos nėra faktinės būsimos Grand Vila migracijos bandymas. Auditą baigiantis bendro core regression nebuvo vykdomas, nes source nekeistas. Įgyvendinimo užduotyje reikalingi atskiri savo branch/worktree, GitHub scope, journal, `core-upgrade-check`, abu validatoriai ir tikri core/SEO/integraciniai testai. Main merge, kito PC fetch, nišos adapterio įdiegimas ir priėmimas lieka atskiri įvykiai.
