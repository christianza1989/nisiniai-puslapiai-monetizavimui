# SEO / GEO parengtis ir matavimo ribos

2026-10-09 saviauditas; native package `ed39a276...2e7b`. Vietinis HTML bei automatinė turinio projekcija ir realus matomumas paieškoje vertinami atskirai.

Gidai pateikia dokumento pasirinkimo, PDF kelio, integracijos atsakomybių ir nuotolinės sesijos priėmimo atsakymus. Iliustraciniai scenarijai nėra klientų projektai. Organization autorius yra MB Pinet pagal dabartinę Core konfigūraciją; jis nėra išgalvotas žmogaus ekspertas. Šios organizacijos ir info@pinet.lt tinkamumas faktiniam savininko pardavimų kanalui dar turi būti patvirtintas prieš paleidimą. Modelių šaltinių apimtis sukonkretinta pagal paties gamintojo modelį, ne vien bendrą eSignatureOffice aprašymą.

Saviauditas aptiko: V1 `/llms-full.txt` praleido10 homepage teksto dalių, nors jos matomos HTML. Bendras reading-body adapteris dabar įtraukia patvirtintą StepOver native home body; esamas tractor adapteris ir kitų custom-home hidden-body ribos išlaikyti. Tai nėra antras publishing predicate. Patvirtinimas, host, laikas, nuorodos ir medija lieka tos pačios public projection atsakomybė. Atšaukimo/izoliacijos bendros regresijos ir šios nišos istorinis tikro laiko HTTP bandymas nurodyti CONTENT_READINESS.md.

| Tikrinimas | Ką vietinis įrodymas gali pasakyti |
|---|---|
| Canonical Host robots | Public robots leidžia skaitymą ir nurodo savo sitemap. Preview localhost turi `Disallow: /` ir noindex; tai teisinga peržiūrai. |
| Googlebot, Bingbot, OAI-SearchBot, PerplexityBot | Bendras robots parser / HTTP politika nėra tikro crawler apsilankymo ar CDN/WAF IP prieigos įrodymas. Gyvo domeno tinklas ir operatoriaus nustatymai NEPATVIRTINTI. |
| GPTBot / Google-Extended / user-fetch | Mokymo ir žmogaus inicijuoto užklausimo paskirtys skiriasi nuo paieškos. Dabartinė wildcard politika nėra savininko atskirai pasirinktas training apribojimas. |
| GSC / GA4 / Bing | Treg my_tools saviaudito metu0 connected tools. Indeksavimas, canonical pasirinkimas, AI ataskaitos ir konversijos NEIŠMATUOTOS, ne nulis. |
| AI citatos | Consumer paieškos / API atsakymai nevykdyti; nėra pateikto citation-share skaičiaus. |

Aktualios [Google generatyvinės paieškos gairės](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide?hl=en), patikrintos2026-10-09: svarbūs naudingi originalūs atsakymai, įprastas SEO, indeksavimas ir įtraukimo nustatymas Search Console. Google savo Search sistemose ignoruoja llms.txt; jo pataisa nėra Google pozicijų priemonė ar AI citatos garantija. Atskirai patikrinti konkrečios property įtraukimo nustatymą ir [Generative AI performance report](https://support.google.com/webmasters/answer/16984139), jei prieinamas; neturint property prieigos jo būsena nežinoma. Ankstesnių bendrų AI-features gairių aprašymo neprilyginti naujos property nustatymų patikrai.

[OpenAI crawler dokumentacija](https://developers.openai.com/api/docs/bots) skiria OAI-SearchBot paieškai, GPTBot mokymui ir ChatGPT-User žmogaus užklausai. Roboto UA suklastotas vietinis užklausimas neįrodo tikro roboto prieigos. Native robots wildcard leidimas turi būti sutikrintas su tikru host/CDN/WAF paleidžiant; SMTP ir privatumo priėmimas atskiri.

Pasiūlytas fiksuotas LT/lt matavimo rinkinys po gyvo priėmimo: „Kaip pasirinkti parašo planšetę verslui?“, „Kaip pasirašyti PDF klientų aptarnavimo vietoje?“, „Kokios programos reikia parašo planšetei?“, „Kaip integruoti parašo planšetę su dokumentų sistema?“, „Ar parašo planšetė veikia terminaliniame serveryje?“, „Ar parašo planšetė savaime suteikia kvalifikuotą elektroninį parašą?“. Brand diagnostika atskirai: StepOver/signotec pirkimas Lietuvoje. Tai pasirinktos skaitytojo užduotys, ne išmatuotos query volumes.

Kiekvienam naujam leistam matavimui saugoti engine/surface, LT kalbą ir faktinę vietą, timestamp, originalų atsakymą, domain citation URL, nesėkmę/cache/replay bei imties vardiklį. Neskaičiuoti skirtingų engines bendru „rinkos share“. Treg 2026-10-08 SERP kvitai dar naudojami tik savo nurodyto TTL ir locale ribose; mobile head503 ir Cloro neecho rezultatai nepatvirtina LT mobile pozicijų. Papildomų mokamų matavimų saviauditas neatliko.
