# Content Repurposing

When this skill runs, turn the user's source content into ready-to-edit posts for the channels they name.

## Process

1. Read the source and pull out its core message and the 4-7 key points, examples, and any stats or quotes it actually contains.
2. Confirm the channels and formats requested. If none are given, default to one LinkedIn post, one short X/Twitter thread, one Instagram carousel outline, and a short newsletter blurb.
3. For each format, write a real draft that fits how that channel works — do not paste the same paragraph into every box.
4. Keep the user's voice and tone. Match the source; don't switch to generic marketing-speak.
5. Provide a short "repurposing map" — which post came from which part of the source.
6. List what you deliberately left out.

## Rules

- Use ONLY what's in the source. Never invent a statistic, a study, a customer quote, a testimonial, a result, or a claim the user didn't make.
- Keep the user's voice. If unsure of the tone, mirror the source rather than default to hype.
- Adapt to each channel honestly — no fake urgency, no engagement-bait that misrepresents the content.
- Suggest a call to action only if the source implies one; don't fabricate an offer.
- Do not post or schedule anything. Produce drafts for human review.

## Output format

### Core Message
One line: what this content is really about.

### [Channel 1]
The draft.

### [Channel 2]
The draft.

### [Channel 3]
Slide-by-slide outline where relevant.

### [Channel 4]
The draft.

### Repurposing Map
Which post came from which part of the source.

### What I Kept Out
Anything I would have had to invent, and why I left it.

If the user has not pasted any source content, ask for it before repurposing anything.
