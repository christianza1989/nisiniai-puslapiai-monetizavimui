# Six-card experience section — asset pack v1

Prepared for the owner's selected six-card ImageGen concept. The asset preparation was followed by homepage integration: all six cards now
prepare their corresponding website-only simulator scenarios.

## Deliverables

- Six integrated illustrations, each 1536 × 1024 with genuine transparent alpha.
- Thirty responsive WebP files: 360, 640, 800, 1200 and 1536 pixels wide per card.
- Fifteen SVG icons, reused from the PhoneBridger vector system; the diagonal
  arrow adapts the existing 24px outline geometry. `icons.svg` is the sprite.
- `components.css`: card surfaces, typography, responsive grid and button
  default/hover/active/keyboard-focus/reduced-motion states.
- `manifest.json`: copy, English alt text, recommended srcset/sizes, source
  hashes and per-file hashes. `preview.html` demonstrates the complete pack.

Runtime assets: `prototype/assets/experience-v1/`. Exact built-in ImageGen
prompts: [section-assets-prompts.json](section-assets-prompts.json); source and
variant metadata: [section-assets-manifest.json](section-assets-manifest.json).
The source PNG masters and accepted concept remain in the original application
workspace `design/website/homepage/.impeccable/experience-v1/`; no raster masters
were copied into the GitHub prototype. The selected sixth master is
`06-phonebridger-v2.png`; the earlier variant is retained as a discarded draft.
Public files are generated by the existing shared `optimizeRaster` pipeline
with its `responsive-webp-v1` policy, preserving alpha and stripping metadata.
The masters remain unmodified. No alternative optimizer was introduced.

## Integration

Use these assets as illustrations, with live HTML headings and buttons. Each
card is a single integrated image; no assembly of separate phones or screens
is required. Use `object-fit:contain` and preserve the 3:2 ratio to avoid cutting
off devices. The separate SVGs use currentColor through the sprite. Fonts reuse
the site's self-hosted Manrope files and their existing OFL licence.

Preview: `/__projects/phonebridger/assets/experience-v1/preview.html` on the
loopback core development server. Preview buttons only display their intended
action; the actual homepage hooks are implemented in `scenarios.js`. Desktop/mobile QA is saved in
`qa/section-assets-desktop.png` and `qa/section-assets-mobile.png`.
Implemented homepage invitations: enter mouse demo, open a chat, send Sheets, drag a desktop file
to a chosen phone and choose its destination folder, open audio, open PhoneBridger.
In-image interfaces, toggles and file buttons are illustrative bitmap content;
actual interactive controls belong to the simulator implementation.

All display copy is English. The generated contact and scenery are fictional.
The generated UI and icons illustrate third-party apps; this is not endorsement.
