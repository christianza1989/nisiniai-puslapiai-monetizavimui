# Everyday apps — selected centered composition

Implemented at #features after the four-offer conversion section and before
connections. The approved centered concept was refined as v6. Independent
backdrop, laptop and phone layers preserve reflow; headline, side cards, lower
three-column rail and demo CTA remain editable English HTML/CSS.

Three built-in ImageGen masters: opaque workspace 1672×941, transparent laptop
1536×1024 and transparent Android body 866×1817. Source originals and concept
images remain in the owner's PhoneBridger workspace under design/source/everyday-apps-v1
and design/website/concepts/everyday-apps-v1. Their prompt, role and lineage
records are retained there. The private snapshot copies only runtime derivatives
and vectors that its manifest lists; it does not copy the owner's real Gmail
screenshot. Gmail and Android chat screens are authored SVG with invented
English sample data, not authenticated accounts or generated readable text.

Twelve lossless responsive WebP variants total 4,447,430 bytes; originals are
not enlarged. Existing website asset pipeline exports the families. No separate
core optimizer was introduced. Runtime SVGs include the consistent line sprite,
four app marks, complete HELLO/Enter keys, link/audio handoffs and the smaller
decorative cursor. That cursor is page artwork, with no input engine changes.

Source kit checks cover seven widths. Actual homepage checks cover six widths,
Features navigation, section order, loading, no horizontal overflow/clipping,
CTA keyboard focus and #workspace destination, plus the existing conversion
summary. The copied snapshot's manifest verifies every byte. Actual existing
core middleware is checked on an isolated server; startup-cached preview is not
restarted. See VERIFY.md and qa/everyday-apps-* for scoped evidence.

Illustrative generated device geometry and small key legends remain a limitation.
Audio support/permission and installed-app link fallback are stated in live copy.
No pricing, real checkout, native release, backend or public deployment is added.
