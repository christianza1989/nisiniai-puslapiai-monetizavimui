# StepOver naturaSign Pad Classic

„naturaSign Pad Classic“ – plona parašo planšetė su nespalvotu ekranu. Jos ekranas rodo parašą ir trumpą tekstą, o dokumentą žmogus gali perskaityti kompiuteryje. Nedidelį, apie 150 g sveriantį įrenginį patogu vežtis į susitikimus.

## Kaip naudojama

Ekrano vaizdą galima pasukti kairiarankiui arba dešiniarankiui. Biometriniai parašo duomenys šifruojami planšetėje; jiems iššifruoti reikalingą privatų raktą saugo notaras. Dokumentui pasirašyti naudojama atskira StepOver programa. RDP ir Citrix aplinkoms gamintojas siūlo papildomus TCP ir Citrix modulius.

2048 bitų režimui PDF nurodo eSignatureOffice ≥5.0, SimpleSigner ≥7.0, Device API ≥5.6. Ilgesniam raktui: eSignatureOffice ≥6.2, SimpleSigner ≥7.1, Device API ≥6.2, Signature API ≥4.13; įrenginio programinė įranga ≥5.05.0.3031. macOS, Linux ir plonųjų klientų naudojimą reikia suderinti pagal pasirinktą programą.
