# Lossless literal runtime transport

Flesco KFLS001WW002 passed the unchanged complete source-wire, geometry/PBR and runtime chain: 768 states, 8,832 measured transitions, 60,028 raw responses and 8,849 geometry observations. Geometry/PBR checked 768 states, all 192 distinct scenes and 10,385 complete source/staged/observation file hashes. Its original compiler runtime is 8,213,466 bytes, above the existing 8,000,000-byte loader/stager limit. Raising that limit or reducing geometry is unnecessary.

The staging adapter can remove only repeated non-finish assignment entries whose values are identical in both source and destination defaults. Every actual changed value, every finish assignment, every anchor/default/choice/transition, original geometry pointer and all remaining metadata stay intact. The original compiler output and prepared proof remain unchanged. Exact reconstruction restores the full original metadata; the existing catalog engine already supports these partial measured assignment maps.

Packing is attempted only for an otherwise sealed runtime exceeding the original limit. The same 8,000,000-byte runtime and 25 MiB geometry limits still reject oversized output. Nonliteral runtimes and incomplete destination maps fail closed. Existing runtimes below the limit retain their original bytes.

Before publishing any packed runtime, run `node --import tsx scripts/verify-chair-runtime-transport.mjs --original=... --transport=... --proof=...`, then the unchanged `check-chair-structure-runtime.ts` against the original closed source and a separate directory containing the transported runtime. Require complete original/transport metadata reconstruction, equal full selections and supplier codes, choices, tokens and all measured transitions. Bind both original and transport SHA-256 in the batch proof. The candidate loader, compiler, raw verifier and Native runtime stay unchanged.

Actual Flesco output is 5,354,906 bytes after 134,400 redundant non-finish assignments are omitted. Exhaustive independent parity and the unchanged runtime checker passed all 768 states and 8,832 transitions. Seven packing/staging regressions, 14 candidate/workflow regressions and the actual new-model loader/launch blocker passed. These results permit technical preview staging; publication still requires build/asset-preservation/dry-run and new HTTP/runtime/original-initial-GLB SHA proof. Editorial and full browser acceptance remain separate.
