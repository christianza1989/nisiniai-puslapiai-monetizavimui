# Salonų ir meistrų katalogas

Mode: Operate. Extend the existing Madbeauty white/black/violet DM Sans world and search-result cards. Visitors compare publicly approved providers by city, price and actual completed-visit review summary, then open services in a profile. Preserve booking, upload moderation and private workspace boundaries.

National URLs: `/salonai`, `/meistrai`. City URLs: `/{salonai|meistrai}/miestas/{cityId}`. Native GET filters work without JavaScript; the enhanced application retains these URLs. Empty city pages and filter variants stay noindex; only populated real city pages and approved real profiles enter sitemap. All 103 supported cities are selectable.

The map shows the selected publicly approved location through the existing OpenStreetMap iframe integration. A card selects another location. It does not claim a multi-marker map or geocoding for profiles with no coordinates. Existing gallery editor supports captions, service links, ordering, portraits and reviewed publication; generated category illustrations are not real provider work.

SEO recovery keeps the exact published server HTML, canonical, robots and structured data if client enhancement fails on that same route. Private/API routes stay excluded. LocalBusiness uses actual visible reviews; zero-review providers have no aggregateRating. Google decides indexing and rich-result appearance.

Verification: pure projection/tree tests, exact pinned production artifact in isolated native Workers/SQLite, actual browser desktop/mobile, controlled blocked-API browser, canonical deployment and Search Console live inspection. Test fixtures never write production data or send external mail.
