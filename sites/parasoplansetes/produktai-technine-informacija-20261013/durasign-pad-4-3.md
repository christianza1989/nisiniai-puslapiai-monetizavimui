# StepOver duraSign Pad 4.3

„duraSign Pad 4.3“ – kompaktiška 4,3 colių parašo planšetė darbui biure arba vykstant pas klientą. Apšviestame ekrane matomas parašas, trumpa informacija ir valdymo mygtukai. Grūdintas stiklas dengia rašymo paviršių.

## Kaip naudojama

Rašiklį galima laikyti vertikaliai arba paguldyti į laikiklį. Budėjimo metu ekrane galima rodyti savo logotipą. Parašo biometriniai duomenys šifruojami įrenginyje. PDF dokumentams pasirašyti reikalinga StepOver programa, o terminalinio serverio ar Citrix ryšiui – atitinkami papildomi moduliai.

## Programos ir prijungimas

PDF nurodyti minimumai: eSignatureOffice ≥7.3, SimpleSigner ≥8.1.0, Device API / Signature API ≥3.1.0, PadConnector ≥3.1.0. Įrenginio atpažinimas operacinėje sistemoje ir konkrečios pasirašymo programos suderinamumas tikrinami atskirai.
