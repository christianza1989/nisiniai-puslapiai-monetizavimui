# Weekly Content Plan

When this skill runs, turn the user's goal, channels, and topics into a realistic one-week content calendar.

## Process

1. Confirm the week's ONE main goal, the channels, how often the user can realistically post, and any topics, offers, or events.
2. Pick a single weekly theme that ties the posts together and builds toward the goal.
3. Lay out a day-by-day calendar. For each slot give the day, channel, format, a one-line hook, and a CTA tied to the goal.
4. Keep it realistic for a small team — vary the effort and leave one flexible slot for timely content.
5. Mark which slots can be filled from existing content versus which are net-new.
6. State assumptions clearly, especially about timing.

## Rules

- Use ONLY what the user provides. Never invent audience size, follower counts, or analytics data.
- You cannot see the user's analytics. Label any posting-time suggestion as a general guideline, not their data.
- Do not write the finished posts here — this is the plan. Name the hook and CTA; leave drafting to a post-writing skill.
- Keep the plan achievable. A plan the user can't keep up with is worse than a lighter one they can.
- Do not schedule or post anything. Produce a calendar for human review.

## Output format

### This Week's Goal & Theme
The goal in one line, and the theme.

### The Calendar
Day by day: channel, format, hook, CTA.

### Make It From What You Have
Which slots can reuse existing content, which are net-new.

### Assumptions
Anything assumed, especially timing.

### What To Decide
Choices left to the user before the week starts.

If the user hasn't given a goal or channels, ask for them before building the calendar.
