## Source and runtime identity

scripts/prepare-pc2-chairs.ts checks the original first-five qualification receipt against the current package manifest. It never queries the supplier. Normal staging checks every payload SHA and byte count, reads back the copy, preserves original GLB bytes and rejects JSON over15MB or GLB over25MiB. It requires fresh D60/E150 resources and an E physical output directory. Validation-only and binding-only modes perform source checks without staging or building.

Selector admission reads the actual original GLB JSON/BIN: own asset SHA, exact scene-root source node and primitive, unique selector/address, unchanged original world matrix and normalized embedded PBR/image identity. These first five packages have flat world-matrix selectors. Nested paths, transforms requiring an unimplemented interpretation, animations or skins fail closed. Opaque geometry/surface hash algorithms are not guessed; unchanged file SHA plus exact original primitive addressing is the identity proof.

PC2 indexes some surfaces on mutually exclusive components. Every binding must belong to this package and match its own selector/base material. Only currently assembled asset addresses are applied; inactive variants never identify a visible surface by name or a shared material/geometry hash. A full-state record is an original-relative override and cannot be merged with another record. Partial-state records require their exact captured construction and finish scope. The initial partial context and component tuples match the observed base scope when that tuple exists.

The browser verifies active GLB bytes before parsing, uses GLTFLoader node/primitive associations, verifies each used texture's HTTP bytes/SHA, preserves normalized PBR texture transforms and samplers, and clones replacement materials. Every selection restores original material references first. Late asynchronous loads and failed material loads cannot leave a previous or partially mixed state. Cleanup restores originals and disposes owned clones, textures and blob URLs. Chair originals bypass the generic upholstery heuristic.
